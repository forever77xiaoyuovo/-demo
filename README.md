# 像素小屋建造游戏原型 Demo
AI辅助UGC建造游戏原型Demo｜玩法设计与原型落地
使用Codex生成Phaser网页游戏代码，独立完成全部玩法、交互、数值设计。

## 🎮玩法介绍
玩家在野外地图探索，首先拾取斧头；持有斧头后，靠近树木、岩石，按空格键采集木头、石头资源。收集材料后前往建造地基，消耗资源搭建墙体、屋顶，完成小屋即可通关。

原型设计亮点：
- 工具前置采集机制：必须找到斧头，才可以开采资源，设置阶段性探索目标
- 资源消耗建造循环，玩家获得创造成就感，贴合UGC创作类玩法
- 全部画面使用代码绘制像素图形，不依赖外部贴图，低成本快速验证游戏创意

## 游玩方式
下载index.html，双击使用浏览器打开，WASD/方向键移动，空格交互。
